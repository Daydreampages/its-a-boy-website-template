# It's a Boy – Baby Shower Website Template 🎉

A stylish, mobile-friendly baby shower website built with HTML and CSS.  
This version uses a dark background theme with soft baby blue and mint accents. Great for digital invites and RSVP pages!

---

## 🎨 Features
- Fully customizable HTML + CSS
- Mobile-optimized layout
- RSVP button (connects to Google Forms or link)
- Optional photo gallery (Gallery version)
- Editable fonts, colors, and text
- Designed for “It’s a Boy” themes

---

## 💡 How to Use
1. Download the ZIP and unzip the folder.
2. Open `index.html` in any browser to preview.
3. Replace placeholder text (names, date, location).
4. Customize colors and images in `style.css` and `/assets/`.
